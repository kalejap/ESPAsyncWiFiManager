- Architectures: `esp8266`, `esp32`

## Purpose
This library provides an asynchronous WiFi connection manager for ESP8266 and ESP32 boards.
It uses `AsyncWebServer` to host a configuration portal, manage WiFi credentials, and support OTA update workflows.

## Key features
- Captive portal for WiFi setup
- Async web server integration
- Remote OTA update support (`/ota/remote-start`, `/ota/remote-progress`)
- ESP8266 and ESP32 compatibility
- JSON-based firmware manifest handling

## Important files
- `library.properties` — library metadata and dependency declarations
- `README.md` — library description and fork reference
- `src/ESPAsync_WiFiManager.h` — public API header
- `src/ESPAsync_WiFiManager.hpp` — implementation declarations
- `src/ESPAsync_WiFiManager-Impl.h` — core implementation, including OTA and web handlers
- `src/WiFiManagerLangResources.h` — embedded HTML/JS resources used by the portal

## Repository context
In this project, the library is used from PlatformIO dependency cache at:
`G:\IoT\IoTApplicationDemo\.pio\libdeps\esp12e\ESPAsyncWiFiManager`

The key integration point is remote firmware update through the built-in web UI. Changes to OTA flow should preserve:
- async response behavior
- progress reporting on `/ota/remote-progress`
- compatibility with both ESP8266 and ESP32

## Usage guidance for Claude
When editing or reviewing this library:
- Prefer minimal, portable changes.
- Keep the async server responsive during long-running operations.
- Do not break compatibility with existing `AsyncWebServer` request handlers.
- Respect Arduino/PlatformIO library conventions.

## Generated files
File `src/WiFiManagerLangResources.h` is generated by batch file `src/srcHtml/makeHtml.bat`, so this 
file should not be modified by developers or AI tools. Instead modify corresponding source files that are stored
in `src/srcHtml` folder.
